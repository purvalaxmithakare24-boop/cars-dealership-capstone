# Cars Dealership - Full Stack Development Capstone Project

**Repository Name:** cars-dealership-capstone

**Project Name:** Cars Dealership Web Application

## Project Description

This project is a full-stack web application developed as part of the Full Stack Development Capstone Project.

The application is designed for a national car dealership in the United States. It allows customers to search for car dealerships, view dealership details, read customer reviews, and submit their own reviews.

## Technologies Used

- React.js
- Django
- Flask
- Node.js
- MongoDB
- SQLite
- Docker
- Kubernetes
- GitHub Actions
- IBM Cloud Code Engine

## Main Features

- User registration and login
- View all car dealerships
- Search dealerships by state
- View dealer details
- Read and submit customer reviews
- Sentiment analysis of reviews
- Responsive website design

## Project Objective

To develop a user-friendly car dealership platform that helps customers find dealerships and share their experiences through reviews.
